Ridwan Ibrahim - portfolio website
Files: index.html, style.css, script.js, ridwan.jpg, Ridwan_Ibrahim_Resume.pdf, img/ (no build step needed).
Open index.html in a browser, or drag this folder onto Netlify to host it.
Project screenshots: copy the files from your old site's img folder into img/ (see img/README.txt). Without them the cards show an emoji instead.
Edit projects, skills (groups) and timeline (jobs) at the top of script.js.
Replace ridwan.jpg to change the hero photo, or the PDF to update the resume (keep the file name).
